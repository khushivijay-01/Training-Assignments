1) Install Git on your system.
- Step 1: Download the Git for Windows Installer 
    -Go to the official Git for Windows website. The download of the latest version (64-bit or 32-bit, depending on your system) should begin automatically. 
Step 2: Run the Installer 
Step 3: Keep default settings and select:
    -Git Bash Here
    -Git from the command line and also from 3rd-party software.
Step 4: Click Install
Step 5: Verify installation.

2) Verify the installation 
- use command :
    git --version / git -v

3) Configure Git with your name and email. 
-  configuration commands:
    - git config --global user.name "[firstname lastname]"
    - git config --global user.email "[valid-email]"

4) Check the configured details.
-  git config --global --list
